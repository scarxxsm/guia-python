## Variables y Tipado Dinámico

Las variables en programación son un **espacio en la memoria de la computadora**, sirven para guardar un valor o un dato.

*Características principales en Python:*
- Fundamentos en objetos, todo es un objeto
- Sensibilidad a las mayúsculas, no es lo mismo "Hola" y "hola"
- Se usa Snake Case (todo en minúsculas). Ejemplo: ``mi_variable_nueva = 10``
- Tipado Dinámico (Se explica a continuación)

En otros lenguajes como lo es Java, cuando declaramos una variable se debe especificar su tipo.
Por ejemplo:
```java
String nombre = "Juan";
int edad = 24;
double precio = 3.57;
```
Sin embargo, Python usa **Tipado Dinámico:** el lenguaje detecta el tipo de variable según el valor
que le asignes.

### Tipos Primitivos en Python

| Tipo | Nombre Técnico | Ejemplo de Código en Python | Nota |
| ----------- | ----------- | ----------- | ----------- |
| Entero | int | `edad = 25` | No tiene límite de tamaño. |
| Decimal | float | `precio = 19.99` | Maneja altaprecisión decimal. |
| Texto | str | `nombre = "Alexis"` | Se deben usar comillas simples ' ' o dobles " " |
| Booleano | bool | `activo = True` | Deben empezar obligatoriamente con mayúscula: True o False. |

>En Python NO es necesario especificar si es Entero o Decimal.

### Concatenación
En programación significa *unir* o *pegar* dos o más elementos para formar uno solo. 
Normalmente usamos el signo de más *" + "*.

> Regla de oro: Solo puedes concatenar elementos que sean del mismo tipo. Si intentas mezclar tipos diferentes directamente, Python se confundirá y marcará un error.

- Ejemplo con str:
```python
print("Oscar" + " Alexis")
## Esto devuelve: Oscar Alexis
```
¿Qué pasa con los números?
- str:
```python
print("5" + "3")
## Esto devuelve: 53
```
- numérico:
```python
print(5 + 3)
## Esto devuelve: 8
```
¿Qué pasa si tenemos una variable de tipo numérica y necesitamos *concatenarla* con una str?

- ``str(x)``
```python
edad = 18
print("Mi edad es: " + str(edad)) ##convertimos la edad(numérica) en texto(str)
## Esto devuelve: Mi edad es: 18
```
Si no se hace esto nos daría error.
Otra forma de hacerlo es usando **F-Strings** (La forma más recomendada). Por ahora lo veremos de forma básica si quieres profundizar en ellos: [video de 4 minutos](https://youtu.be/jS01i00n78c?si=qTKRoLeiLDyjIKjo)

- F-Strings:
```python
edad = 18
print(f"Mi edad es: {edad}")
## Esto devuelve: Mi edad es: 18
```
Importante que inicie con **f** y que la variable este entre **corchetes: {}**

## Operadores

### Aritmeticos:
Estos sirven para realizar operaciones matemáticas.

| Tipo | Sintaxis | Ejemplo | Output |
| :----------- | :-----------: | :-----------: | :-----------: |
| Suma | + | `4 + 5` | 9 |
| Resta | - | `9 - 3` | 6 |
| Multiplicación | * | `5 * 3` | 15 |
| División | / | `20/4` | 5 |
| División entera | // | `7//2` | 3 |
| Exponente/Potencia | ** | `4**2` | 16 |
| Módulo(residuo) | % | `7%2` | 1 |

### De Comparación y Lógicos:
Estos se usan normalmente en sentencias condicionales y siempre devuelven un booleano (True o False).

| Tipo | Sintaxis | Ejemplo | Output |
| :----------- | :-----------: | :-----------: | :-----------: |
| Igual | == | `4 == 4` | True |
| Diferente | != | `4 != 6` | True |
| Mayor | > | `9 > 2` | True |
| Menor | < | `3 < 8` | True |
| Y | and | `True and True` | True |
| No | not | `not False` | True |
| O | or | `True or False` | True |

## Control de flujo

Python no usa llaves *{}* para crear bloques de código.
En su lugar usa la **identación** (4 espacios o un tabulador).
También se usan los dos puntos (**:**) para indicar el inicio de cada bloque.
