## Condicionales: if, elif, else

Los condicionales son metodos que nos permiten, como dice su nombre, saber cuando una confición se cumple. Aunque podemos pensarlos como preguntas de 'sí' y 'no', Python no se limita solo a las respuestas True y False, sino que evalúa la 'verdad' o 'falsedad' de cualquier objeto.

> En este tema trabajaremos mucho con los **operadores**, si no los recuerdas puedes revisar en archivo *1.2_Variables_Operadores*

### if:

**if** se traduce directamente al español como "si", ejemplo:

- **if** acabaste tu tarea, **entonces** sal a jugar
- **if** tienes sueño, **entonces** duerme

*Sintaxis:*

```python
if condicion:
    instruccion_unica
```
Es importante recordar el *control del flujo* en python. Todo lo que contiene el **if**, debe de estar dentro de un bloque de código, para crear este **"bloque"** ponemos **":"** al final de la linea (como en el ejemplo), y la siguiente línea debe comenzar con un tabulador (cuatro espacios o un tab).

*Ejemplo:*
```python

edad = 20
if edad >= 18:
    print("Admitido, eres mayor de edad")
```
Este código nos arrojaría este mensaje: *Admitido, eres mayor de edad*, ya que la edad que declaramos fue 20, como 20 es mayor que 18 la condición se *cumple*.

---

En muchos casos es necesario utilizar mas de un condicional, por ejemplo en en cuestionario:
Supongamos que queremos automatizar el acceso a un club, dependiendo la edad del usuario, se le otorgará una etiqueta distinta
- 18 - 25 --> verde
- 26 - 32 --> roja
- +33 --> amarilla
- -18 --> Sin acceso 

Lo bueno de la progrmación es que existen muchas variantes para resolver los problemas, en esta ocasión veremos las más básicas.

Opción 1:
```python

if 18 <= edad <= 25:
    print("verde")
if 26 <= edad <= 32:
    print("roja")
if edad >= 33:
    print("amarilla")
if edad < 18:
    print("Sin acceso")

```
Este código funciona pero hay más formas de hacerlo, por ejmplo, usando **elif** -->
## elif
**elif** nos es útil cuando solo necesitamos que *una* de *todas* las condiciones se cumpla. **elif** siempre va después de un **if**.
Por ejemplo si necesitamos verificar varios parametros en los que devolveremos un distinto valor usamos **if**, de esta manera nos aseguramos de que cada condición sea leída. Cuando usamos **elif**, el programa dejará de leer las demás condiciones cuando encuentre una que se cumpla. 
Volviendo a nuestro ejemplo anterior quedaría de está manera:

Opción 2:
```python

if 18 <= edad <= 25:
    print("verde")
elif 26 <= edad <= 32:
    print("roja")
elif edad >= 33:
    print("amarilla")
elif edad < 18:
    print("Sin acceso")

```

Anteriormente al usar unicamente **if** no importaba si el usuario cumplia la primera condición, *18 <= edad <= 25*, el programa seguía leyendo las demás condiciones en busca de mas coincidencias. 
En cambio, ahora que usamos **elif** si el usuario cumple la primera condición, *18 <= edad <= 25*, el programa dejará de leer las demás coincidencias porque sabe que no se cumplirán o que no es necesario que se cumplan.

**elif** es útil cuqando tenemos que verificar que unicamente una condición se cumpla.

## else 

Hay veces en las que ninguna condición se van a cumplir, si solo hacemos uso de **if** y **elif** y ninguna condición se cumple, el código no hará nada. Para eso usamos **else**, traducido directamente: *sino**.

- **if** acabaste tu tarea, **entonces** sal a jugar, **else** castigado
- **if** tienes sueño, **entonces** duerme, **else** ponte a trabajar

**else** nos es útil cuando queremos que sin importar el input del usuario, el programa ejecute una acción.

Ejemplo:

```python

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")
```
Esto funciona porque, si ingresas cualquier numero menor a 18, la primera condición no se cumple y cae en el **else**

*Ejemplo donde usamos los tres condicionales vistos:*

```python
edad = 18

if edad < 13:
    print("Eres un niño.")
elif edad < 18:
    print("Eres un adolescente.")
else:
    print("Eres mayor de edad.")
```

## Operadores de pertenencia (in / not in)

Sirven para verificar de manera directa si un elemento se encuentra dentro una colección o un texto.

Sintaxis:

Para verificar si un elemento **ESTÁ** en la secuencia:
```python
elemento in secuencia
```

Para verificar si un elemento **NO ESTÁ** en la secuencia:
```python
elemento not in secuencia
```
- Ejemplo práctico:

```python
frase = "Aprender Python es divertido"
print("Python" in frase)  # Devuelve True
```

Lo que hace es verificar si *"Python"* esta en la variable *frase*.
Como *frase* contiene la palabra *"Python"*, entonces duevuelve *"True"* (verdadero)

## Coincidencia de Patrones (match-case)

La estructura `match-case` fue introducida en Python 3.10. Se le llama **Pattern Matching (Coincidencia de Patrones)**.
Esto se debe a que no solo compara valores fijos, sino que tambien la *estructura*, *tipos* y *atributos* de los datos.

Sintaxis básica:

```python
match variable:
    case VALOR_1:
        instrucciones
    case VALOR_2:
        instrucciones
    case _:
        instrucciones

```

Para explicarlo de manera sencilla, utilizaré una analogía de la vida real que he leído y creo que es muy fácil de entender.

- El ascensor de un edificio:

Imagina que te subes a un ascensor y quieres ir al piso 3. ¿presionas el botón del piso 1, 2 y 3? o directamente presionas el tercero. Así funciona `match-case`, verifica que "botón" presionaste y te lleva **directamente** a ese piso.

```python
## Variable
piso = 2

match piso:
    
    ## Ponemos las opciones posibles (casos)
    case 1: ## primer piso
        print("Llegaste a las Oficinas.")
        
    case 2: ## segundor piso
        print("Llegaste a la Cafetería.")
        
    case 3: ## tercer piso
        print("Llegaste al Gimnasio.")
        
    ## el piso que ingresó no es valido
    case _:
        print("Ese piso no existe. Regresando a Recepción.")

```

De esta manera, no importa a que piso vaya el usuario, siempre habrá una respuesta.

*Pero, ¿por qué usar ``match-case`` en vez de ``if``?*
Puedes hacer el mismo trabajo del elevador con ``if``, ``elif`` y ``else``. Sin embargo cuando tienes muchas opciones, por ejemplo diez pisos diferentes usar ``match-case`` hace que tu código sea más fácil de entender y más óptimo.
