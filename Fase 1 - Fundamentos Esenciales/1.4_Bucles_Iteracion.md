## Bucles e Iteración

En programación un **bucle** es una estructura que le dice a la computadora que repita una acción muchas veces. 
**Iterar** es el acto de ejecutar esa acción *una sola vez* dentro de la repetición.

- Veámoslo con una analogía:

Supongamos que vas a crear un código para verificar correos pendientes, y tienes 15 correos sin leer. 

¿Qué es  más óptimo, hacer una función *por cada uno de los correos*, o hacer una función que lea *cada correo* hasta que no quede ninguno?
Efectivamente hacer una función que sólita verifique todos los correos sin leer es mejor quee hacer una por cada uno de los correos.


El **bucle** es la **orden general**: "Mientras existan correos sin leer, revísalos.
La **iteración** es **cada vuelta individual**: Revisar ele primer correo es la iteración 1, revisar el segundo es la iteración 2, y así hasta terminar.

## Bucle for y range()

El bucle for en Python funciona como un "recorredor" que toma elementos de una lista o secuencia, uno por uno, de principio a fin.

- Sintaxis básica:

```python
for variable_temporal in range(a):
    instrucción
```

En la "variable_temporal" regularmente usamos `i`

`a` representa un dato numérico

¿Pero, cómo funciona la iteración en un bucle for en python?
El bucle `for` toma la variable temporal `i`, la cual **siempre que no ingreses más parámetros** empieza en 0. Para saber cuantas veces `i` se repetirá, se apoya de ``range(a)`` donde en vez de "a" ponemos un dato numérico.

- Ejemplo:
```python
for i in range(5):
    print("Hola")
```
La salida de este programa sería `Hola` 5 veces.

> Lo que pasa "internamente":

| i (iteración) | Output |  
| :-----------: | :-----------: |  
| 0 | Hola |
| 1 | Hola |
| 2 | Hola |  
| 3 | Hola |  
| 4 | Hola | 

La ``i`` llega hasta 4, ya que empieza desde 0.

Existen más parámetros que aplicar en un bulce ``for``, también se puede iterar sobre una lista sin embargo, por ahora no veremos ese tema, hasta que veamos listas y tuplas.

## Bucle while

Se ejecuta **mientras** una condición sea verdadera, lo usas cuando no sabes con exactitud cuantas vueltas tomará el problema solo sabes que se dentendrá cuando *la situación cambie.* "Sigue haciendo tal acción mientrás tal condición sea *verdadera*".

- Sintaxis básica:

```python
while condición:
    instrucción
```

- Ejemplo práctico:
```python
bateria = 18 ## variable inicial

while bateria > 0: ## condición
    print("Pila: " + bateria) ## instrucción
    bateria = bateria - 1 ## reducimos la bateria en -1, cada iteración
## esta acción se ejecuta cuando la acción YA NO es verdadera:    
print("Sin pila")

```

Regularmente si queremos hacer que un programa se repita indeterminadamente hasta que usuario salga del bucle usamos ``while True``.

```python

while True:
    accion

```

## Zona de peligro con los bucle while

¿Qué pasa si la condición para que el bucle se detenga nunca se cumple y dentro de este mismo bucle no tenemos algun input que detenga las iteraciones?

Regresando al ejemplo anterior:

```python
bateria = 18 ## variable inicial

while bateria > 0: ## condición
    print("Pila: " + bateria) ## instrucción
    #bateria = bateria - 1 QUE PASA SI ESTA LINEA NO EXISTE
## esta acción se ejecuta cuando la acción YA NO es verdadera:    
print("Sin pila")
```
Si prueban ese código, se convertiría en un bucle sin fin y sin manera de detenerlo, esto porque la condición de que la bateria es mayor a 0 SIEMPRE se cumple, por lo tanto mostraría este mensaje "Pila 18" hasta que cierres el programa.

## Control avanzado 

- **break**

El `break` nos sirve para terminar el bucle inmediatamente.
Para ``for``:
```python
for x in:
    if x == 2:
        break  # Se detiene aquí
    print(x)   # Solo imprime el 1
```
Para ``while``:
```python
x = 1
while x < 10:
    if x == 3:
        break  # Se detiene aquí
    print(x)   # Imprime 1 y 2
    x += 1
```
- **continue**

El `continue` hace que se salte la iteración actual 

Para ``for``:
```python
for piso in range(1, 6):
    if piso == 3:
        print("¡Piso 3 prohibido! Nos lo saltamos...")
        continue  # Salta directo al piso 4, ignorando el print de abajo
        
    print("Subiendo al piso: ", piso)
```

Para ``for``, lo que hace es que deja de leer el codigo debajo y repite el bucle:
```python
contador = 0

while contador < 5:
    contador = contador + 1  

    if contador == 3:
        print("¡El 3 es de mala suerte! Lo saltamos.")
        continue  
        
    print("Número actual: ", contador)

print("¡Bucle terminado con éxito!")
```

- **``else`` en bucles**

El `else`en bucles en un poder especial de Python. Este se ejecuta solo cuando el bucle terminó de manera natural, eso quiere decir que no fue interrumpido por ningur `break`.


Por ejemplo en while:

```python
intentos = 3

while intentos > 0:
    clave = input("Introduce la contraseña: ")
    
    if clave == "1234":
        print("¡Acceso concedido!")
        break  
        
    intentos = intentos - 1
    print(f"Incorrecto. Te quedan {intentos} intentos.")

else:
    print("Cuenta bloqueada. Demasiados intentos fallidos.")

```

Por ejemplo en for:

```python
for numero in range(1, 5):
    if numero == 10:
        print("¡Encontrado!")
        break
else:
    print("El número 10 no se encontraba en el rango.")

```
