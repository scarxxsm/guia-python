# Listas

Imagina que las listas son como una gran caja mágica donde puedes tantas cosas como tu RAM soporte, puedes meter cualquier tipo de dato, incluso otra lista.
Estas nos sirven para agrupar o guardar valores.

- Sintaxis básica:
```python
lista = []
```

La lista puede llevar el nombre que tu desees, pero es muy importante que la declares con `[]` ya que de este modo Python sabe que te estas refiriendo a una lista.

Lo grandioso de esta caja (lista), es que puedes agregar, borrar o modificar los articulos que contiene en cualquier momento. En Python, a esta capacidad de cambiar se le llama **mutabilidad.**

Cabe mencionar que los índices de las listas empiezan en 0.
```python
lista = [2, 4, 6, 8]
# El index 0 es el numero 2, mienttras que el index 3 es el 8
```

## Pero profundicemos un poco más en las listas y sus funciones:

- **Agregar valores a la lista:**

Cuando queremos añadir un elemnto **al final** de la lista, usamos `append()`
```python
lista = [1,2,3,4]
lista.append(5)
# Resultado: [1, 2, 3, 4, 5]
```
---

Sin embargo, cuando lo que quermos agregar a la lista es **otra lista o una String** como char usamos ``extend()``
Esta funcion desempaqueta las listas o cadenas agregandolos uno por uno, eso quiere decir que **solo se debe usar con valores iterables**. No lo puedes usar con un número.
```python
numeros = [1, 2]
numeros.extend([3, 4]) # Resultado: [1, 2, 3, 4]
```

```python
letras = ['a', 'b']
letras.extend('cd')
print(letras) # ['a', 'b', 'c', 'd']
```
Como pudieron ver en los ejemplos, `extend()` añade por char.

---

Pero que pasa si queremos **añadir un elemento en una posición específica de la lista.**
Pues usamos `insert()`, esta función recibe dos argumentos, el index (posición) y la variable. ``insert(i, x)``
```python
lista = [2, 4, 6, 8]
lista.insert(2,5) # En la posición dos, añade un 5 (Las listas empiezas en la posición 0)
# Resultado: [2, 4, 5, 6, 8]
```
`insert()` nunca devolvera un ``IndexError``, si en index escribes un número negativo, la función simplemente lo añadirá al inicio, y si escribes un número muy grande, solo lo pondrá al final de la lista (como un ``append()``) 
```python
valores = ["A", "B"]

valores.insert(100, "Z")  # El índice 100 no existe
print(valores) # Resultado: ["A", "B", "Z"]

valores.insert(-50, "Inicio") # El índice -50 está muy lejos a la izquierda
print(valores) # Resultado: ["Inicio", "A", "B", "Z"]
```
---

- **Remplazar valores de la lista:**

Si sabemos la **posición exacta** del elemento que quermos cambiar, simplemente usamos el index y el operador de asignación (=). ``lista[i] = x``

```python
frutas = ["manzana", "plátano", "cereza"]

# Reemplazar el elemento en el índice 1 ("plátano") por "pera"
frutas[1] = "pera"

# Resultado: ["manzana", "pera", "cereza"]
```
---

Por el contrario, si no conocemos la posición exacta pero si el **valor exacto**, usamos la función ``index()`` para sacar su **posición exacta**.
```python
colores = ["rojo", "azul", "verde"]

# 1. Buscamos el índice de "azul" con la funcion index()
i = colores.index("azul")

# 2. Reemplazamos en esa posición
colores[i] = "amarillo"

# Resultado: ["rojo", "amarillo", "verde"]
```

---

- **Eliminar valores de la lista:**

Para eliminar valores de una lista, una de las funciones más útiles es ``pop()``.
Esta función tiene la cracterística de que se puede usar con y sin argumento.
Por ejemplo:
```python
autos = ["Ford", "Mazda", "Toyota"]

# Sin argumento: elimina el último valor de la lista
autos.pop()
# Resultado: ["Ford", "Mazda"]

# Con argumento: elimina el index seleccionado
autos.pop(1)
# Resultado: ["Ford", "Toyota"]
```
Otra característica útil de `pop()`, es que el valor que eliminemos, lo podemos guardar en una variable.

```python
autos = ["Ford", "Mazda", "Toyota"]

x = autos.pop(1)
print(autos) # Resultado: ["Ford", "Toyota"]
print(x) # "Mazda"
``` 
---

Si queremos eliminar un valor específico usamos ``remove()``.
Es MUY IMPORTANTE saber que solo elimina la primera coincidencia.
```python
nombres = ["Juan", "Pedro", "Juan"]
nombres.remove("Juan") # Quita solo el primer "Juan" -> ["Pedro", "Juan"]
```
---

Por último si queremos eliminar todos los datos de la lista, usamos ``clear()``
```python
numeros = [1, 2, 3, 2, 4, 2]
numeros.clear() # deja la lista vacía []
```
