# Listas

Imagina que las listas son como una gran caja mágica donde puedes tantas cosas como tu RAM soporte, puedes meter cualquier tipo de dato, incluso otra lista.
Estas nos sirven para agrupar o guardar valores.

- Sintaxis básica:
```python
lista = []
```

La lista puede llevar el nombre que tu desees, pero es muy importante que la declares con `[]` ya que de este modo Python sabe que te estas refiriendo a una lista.

Lo grandioso de esta caja (lista), es que puedes agregar, borrar o modificar los articulos que contiene en cualquier momento. En Python, a esta capacidad de cambiar se le llama **mutabilidad.**

**Pero profundicemos un poco más en las listas y sus funciones:**

- Agregar valores a la lista:
Cuando queremos añadir un elemnto **al final** de la lista, usamos `append()`
```python
lista = [1,2,3,4]

lista.append(5)
```

Sin embargo, cuando lo que quermos agregar a la lista es otra lista o una String como char usamos ``extend()``
Esta funcion desempaqueta las listas o cadenas agregandolos uno por uno, eso quiere decir que solo se debe usar con valores iterables. No lo puedes usar con un número.
```python
numeros = [1, 2]
numeros.extend([3, 4]) # Resultado: [1, 2, 3, 4]
```

```python
letras = ['a', 'b']
letras.extend('cd')
print(letras) # ['a', 'b', 'c', 'd']
```
